# Natnael Portfolio

Personal portfolio site for **Natnael Ayalew** — full-stack developer. Built with Next.js (App Router), TypeScript, and CSS Modules.

See [TASK.md](./TASK.md) for the project goal and task plan.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

All routes are prerendered as static content and ready to deploy on Vercel.

## Project structure

```
app/          — layout, page, global styles, icon
components/   — nav, hero, about, projects, experience, contact, footer, reveal, terminal
data/         — typed project/experience data
```
